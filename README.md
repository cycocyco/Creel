# 鱼篓 (Creel)

**高确定性 B站 AI BOT 评论拦截净化器 · 捕杀批量洗稿肥鱼与复读水军**

针对目前 B 站大量真实账号接入 AI 接管、自动刷视频发总结、批量洗稿矩阵的现象深度设计。

---

## 🌟 核心拦截机制

1. **网络数据层直接拦截 (API Hook)**
   - 运行在浏览器原生页面上下文（`document_start` 第一时间挂载）；
   - 彻底拦截并清洗 B 站后端返回的评论响应 JSON，在数据流返回给前端前，直接将命中规则的 BOT 评论剔除；
   - **零闪烁、零延迟、不受任何前端 DOM 或 Web Components (Shadow DOM) 改版影响**。

2. **精准靶向「昵称规则库」（防误杀杀手锏）**
   - 针对当前黑产批量水军号虽然把评论内容调教得很拟人，但**账号昵称具有强批次模板特征**（如 `XX的大肥鱼`、`XX家的DSH`、`XX小鲛鱼`）；
   - 支持关键词模糊匹配（如添加 `肥鱼`，任何包含“肥鱼”的账号无论其评论发什么，一律精准秒杀）；
   - 支持高级正则表达式（如 `/.*家的DSH.*/`）；
   - **双轨隔离**：昵称规则严格只对账号名生效，真实网友在评论里提到这些词绝对不会被误伤！

3. **评论正文特征与 Prompt 残留拦截**
   - 捕杀“作为AI”、“语言模型”、“主人拿自己的活”、“选对壳真的影响钱包喵”等明显的机器人口癖或 System Prompt 遗漏词；
   - 支持多组洗稿数值（如 `96.5` / `97.6%` / `2.2倍` 等）同屏矩阵聚类识别。

## 🎨 界面与交互设计 (Material Design 3 暗色规范)

- **动态红蓝状态重点色**：
  - **捕杀模式（开启）**：激活警戒红 (`#ff5449`)，状态显示 `● 捕杀中`；
  - **放行模式（关闭）**：转为平静蓝 (`#38bdf8`)，状态显示 `● 已放行`。
- **高辨识度圆角矩形底框图标**：温润大圆角底框搭配深色镂空鱼篓剪影，暗色/浅色工具栏均清晰醒目。
- **双模统计机制（单页捕获 + 历史累计）**：
  - 工具栏角标与胶囊默认展示**当前标签页/当前视频捕获数**（刷新或关闭网页自动归零）；
  - 胶囊附带展示 `总X` 历史累计计数，并支持点击一键清零历史总数。
- **面向百级规则的高效容器**：
  - 支持多词批量粘贴添加（空格、逗号或换行自动拆分）；
  - 内置即时搜索栏 (Search Filter)，上百条规则即搜即出；
  - 极简单行 Header，核心输入框与规则列表占据 85% 以上黄金操作区域。

## 🚀 安装步骤

1. 打开浏览器扩展管理页面：
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
2. 打开右上角 **「开发者模式」** 开关；
3. 点击 **「加载已解压的扩展程序」**；
4. 在弹出的文件选择器中，选择本项目的根目录（即包含 `manifest.json` 的文件夹）；
5. 打开 B 站视频评论区即可享受彻底净化的无 BOT 体验。
